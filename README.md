# 🗺️ 대한민국 방방곡곡 여행 지도 (Korea Travel Map) - v2.0 고도화

전국 **167개 시·군(市·郡)** 단위로 나의 여행 발자국을 색칠하고, **전문 여행가 큐레이션 10대 대표 명소(총 1,670개)**와 나만의 여행 메모를 체계적으로 기록하는 인터랙티브 여행 지도 웹앱입니다.

---

## 🌟 v2.0 핵심 업그레이드 내역 (Gemini 심층 벤치마킹 및 초격차 기능)

1. **전국 167개 시·군 직관적 통합 관리**:
   - 복잡하고 파편화된 구(區) 단위를 시·군 단위로 전격 통합하여 실질적인 여행 단위(전국 167개 시·군)로 최적화.
   - 서울특별시(1), 광역시(도심/군 분리 총 11개), 경기도(31), 강원권(18), 충청권(28), 호남권(37), 영남권(47), 제주(2).

2. **5단계 다채로운 방문 등급 시스템**:
   - `👑 거주/고향` (로열 퍼플, Level 4)
   - `🚀 단골/자주` (사파이어 블루, Level 3)
   - `🏕️ 숙박 여행` (비비드 에메랄드, Level 2)
   - `🟢 당일치기` (민트 그린, Level 1)
   - `⬜ 미방문` (소프트 아이스 슬레이트, Level 0)
   - 클릭 한 번으로 기본 숙박 색칠, 상세 서랍에서 원하는 등급을 자유롭게 원클릭 전환!

3. **전문 여행가급 10대 대표 명소 큐레이션 & 네이버 지도 직결**:
   - 167개 시·군 전역에 대해 10개 대표 명소(총 1,670개) 엄선 적재.
   - 각 명소마다 **🗺️ 네이버 지도 바로가기 버튼** 제공 (클릭 시 새 탭에서 실제 위치, 길찾기, 최신 리뷰 직결).
   - `모두 선택` / `모두 해제` 원클릭 퀵 액션 및 나만의 숨은 명소 추가 기능.

4. **지도 지명 라벨 표시 토글 (Map Label Overlay)**:
   - 상단 `🏷️ 지명 표시` 버튼으로 167개 시·군 명칭을 지도 위에 오버레이 표시.

5. **미방문 여행지 랜덤 추천 (🎲 어디 갈까?)**:
   - 아직 가보지 않은 시·군 중 하나를 주사위처럼 추첨하여 지도를 부드럽게 줌인하고 10대 명소를 즉시 브리핑!

6. **인스타/SNS 공유용 고화질 PNG 지도 다운로드**:
   - 내가 색칠한 알록달록한 지도를 1200x1600 고해상도 이미지로 즉시 저장.

7. **완전 무결한 로컬 저장 & JSON 백업/복원**:
   - 브라우저 로컬스토리지 실시간 자동저장 및 기기 간 JSON 파일 이동 지원.
