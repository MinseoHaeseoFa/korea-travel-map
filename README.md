# 🗺️ 대한민국 방방곡곡 여행 지도 (Korea Travel Map)

> **전국 251개 시·군·구 나의 여행 발자국을 색칠하고, 지역별 대표 명소와 추억을 기록하는 인터랙티브 여행 웹앱**

---

## 🌟 주요 핵심 기능

1. **전국 251개 시·군·구 정밀 벡터 지도 (D3.js + TopoJSON)**
   - 서울 25개 자치구, 경기 44개 시·군부터 제주까지 전국 251개 지자체 경계를 경량 벡터(91KB)로 렌더링.
   - 외부 지도 API 연동 없이 즉각 로딩되며 부드러운 줌 & 팬(Zoom & Pan) 지원.
2. **PC & 모바일 듀얼 최적화 반응형 UX**
   - **PC**: 마우스 호버 시 플로팅 툴팁(지역명, 방문 여부, 꼭 가봐야 할 대표 명소 3선 미리보기) + 클릭 시 우측 슬라이드 서랍 패널.
   - **모바일**: 터치 제스처 최적화 + 터치 시 하단에서 부드럽게 올라오는 바텀 시트(Bottom Sheet) 모달.
3. **지역별 대표 명소 체크박스 & 메모 시스템**
   - 251개 시·군·구별 한국관광공사 및 지자체 공인 대표 여행지(3~5곳) 기본 내장.
   - 체크박스 클릭으로 다녀온 명소 체크 및 나만의 숨은 명소 직접 추가 기능.
   - 방문 일자(Date picker) 및 생생한 여행 메모(맛집, 후기, 팁) 기록.
4. **실시간 정복률 통계 & 실시간 로컬스토리지 저장**
   - 방문 지역 수, 전국 정복률(%), 체크한 명소 수 실시간 계산 및 시각화 프로그레스 바.
   - 브라우저를 닫거나 새로고침해도 데이터가 영구 보존되는 LocalStorage 엔진.
5. **데이터 백업/복원 & 지도 이미지 다운로드**
   - PC-모바일 기기 간 이동을 위한 JSON 파일 백업 및 복원 지원.
   - 내가 색칠한 전국 지도를 고화질 PNG 이미지로 저장하여 SNS 공유 및 개인 소장.

## 📁 프로젝트 파일 구조

```text
korea-travel-map/
├── index.html                  # 메인 웹앱 마크업 (반응형 뷰포트, 헤더, 맵 컨테이너, 서랍)
├── style.css                   # 모던 UI/UX 스타일시트 (PC 호버, 모바일 바텀시트, 줌 컨트롤)
├── app.js                      # D3.js 지도 렌더링, 이벤트 핸들러, 로컬스토리지, 이미지 익스포트
├── map-data.js                 # 대한민국 251개 시·군·구 TopoJSON 데이터 (91KB 경량)
├── places-data.js              # 251개 지자체별 공인 대표 명소 큐레이션 데이터베이스
├── korea-sigungu-topo.json     # 원본 시군구 TopoJSON 데이터
└── README.md                   # 프로젝트 설명서
```

## 🚀 배포 및 실행 방법

### 로컬 실행
정적 파일(HTML/CSS/JS)로 구성되어 있어 별도의 빌드 과정 없이 바로 실행할 수 있습니다:
```bash
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

### Vercel 배포
GitHub 저장소(`MinseoHaeseoFa/korea-travel-map`)를 Vercel에 연동하면 별도 설정 없이 1초 만에 글로벌 CDN으로 프로덕션 배포됩니다.
